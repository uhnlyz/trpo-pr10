# Практическая работа № 9 — Корзина, session и контроллер действий

## Результат
Добавлена корзина интернет-магазина. В сессии хранятся только идентификаторы товаров и количество. Сведения о товарах и расчёт суммы берутся из ProductRepository и CartService.

## Запуск
PHP 8.0+: `php -S localhost:8000 -t public`, затем http://localhost:8000.

## Маршруты
- GET /cart — просмотр корзины;
- POST /cart/add — добавление товара;
- POST /cart/update — изменение количества;
- POST /cart/remove — удаление позиции.

Изменение состояния выполняется только POST-запросами. После действия контроллер перенаправляет пользователя на /cart.

## Проверка
Добавьте товар из каталога, измените количество, удалите позицию и обновите страницу. Проверьте пустую корзину и отдельную сессию в приватном окне. Сценарии находятся в dataset/cart_scenarios.json.

## Хранение
В `$_SESSION['cart']` лежат только пары «id товара — количество». Полные сведения получаются через JsonProductRepository. Итоговая стоимость считается в CartService.
